작업자 영상 판독

61장 · 검출 결과와 모델 답변은 표시하지 않습니다
불러오는 중…

작업자가 보이면 오른쪽에서 ‘보임’을 선택하고, 영상 위를 드래그해 박스를 그리세요.

표기 기준

• 사진에서 식별되는 실제 작업자만 표시하세요. 장치·그림자·추측 위치는 제외합니다.
• 박스는 보이는 신체 영역 전체를 감싸세요. 가려진 몸을 상상해서 박스를 늘리지 않습니다.
• 누워 있는지 서 있는지 사진만으로 판단하기 어려우면 ‘자세 판독 불가’를 선택하세요.
• 대상이 너무 작거나 무엇인지 애매하면 ‘존재 판단 불가’를 선택하세요. ‘안 보임’과 다릅니다.
• 박스는 다시 드래그하면 교체됩니다. 아래 좌표는 원본 이미지 픽셀입니다.

이전에 본 프레임이면 노출 여부를 표시하세요. 이번 작업은 기존 자료에 대한 수동 검토이며, 새로운 독립 실험은 아닙니다.

1. 작업자가 보이나요?
2. 사진에서 읽히는 자세
3. 관측 상태

선택·박스 변경은 자동 저장됩니다. ‘판독 완료 · 다음’을 눌러 완료로 표시하세요. ‘다음’만 누르면 미완료로 남길 수 있습니다.

브라우저를 닫아도 저장된 기록은 유지됩니다. 서버를 다시 켜면 이어서 작업할 수 있습니다. 한 탭에서 작업해주세요.
