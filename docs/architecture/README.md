## 기록 방법

- 파일 이름: `YYYY-MM-DD-주제.md`. 같은 날 후속 제안은 별도 파일에 `-v2` 등을 붙인다.
- 기존 제안을 새 설계로 덮어쓰지 않는다. 새 문서에서 이전 제안의 링크와 변경 이유를 적는다.
- 각 제안에 연구질문, 기존 구현, 제안 구조, 대안·선택 이유, 미결정 사항, 완료 기준을 남긴다.
- 후속 문서에는 무엇을 유지·변경·폐기했는지 명시한다. 단순한 구현 진행은 작업 로그에 기록한다.
- 채택 여부와 구현 상태를 구분한다. 구현됐다는 주장은 검증 기록과 함께 남긴다.
