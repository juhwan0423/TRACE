## 쓸 때 지킬 것

- 2장 실패 사례(초기 실험 t0020)와 5장 영상(2026-11-10 별도 시연 demo01)은 **같은 조건의 서로 다른 실행**이다. 한 실행의 수정 전후처럼 설명하지 않는다.
- 영상은 약 4분 실행을 34.5초로 줄인 편집본이다. 모델 응답 대기 구간을 크게 압축했고, 판정 화면은 멈춰서 보여 주며, 이동 구간은 약 6배속이다. 화면은 TRACE 모니터의 형식을 따라 저장된 기록으로 다시 그린 것이며 프로그램 녹화가 아니다. 카드 문구는 저장된 구조화 응답을 풀어 쓴 것이다.
- 7장의 초기 수치와 8장의 재시험 수치를 한 그래프에 섞지 않는다.
- 그래프의 축 라벨은 영문이다. 한글이 필요하면 `.svg`를 편집한다.
- 원본 프레임은 640×360이다. 크게 확대하면 흐려지므로 화면의 절반 이하 크기로 쓴다.
- `s09_cost_limits/panel_gate_passed_on_equipment.png`에서 박스 안이 설비라는 해석은 사후 시각 확인이며, 독립 판독자의 평가가 아니다.
