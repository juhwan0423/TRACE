# 61장 사람 판독 기반 검출기 채점

2026-11-08. 사용자 판독을 바꾸지 않고 저장된 YOLO11n 검출 결과와 대조했다. **현재 confidence 0.25의 게이트를 그대로 40회 비교에 사용하는 것은 권하지 않는다.** 주된 문제는 배경 오검출이며, 단일 후보 규칙만으로 충분히 제거되지 않는다.

## 판독 완료 및 평가 범위

사용자가 입력한 61장 모두 필수 항목이 갖춰져 있었다. 사용자 요청에 따라 완료 표시만 빠진 59장을 완료로 처리했다. 박스·자세·가림·메모 등 판독 내용은 변경하지 않았다. 완료 처리 전 원본과 수정 이력을 `artifacts/person_detector/manual_review_20261108/finalized_v1/`에 보존하고 최종 판독을 고정했다. 판독 화면을 새로고침하면 61/61이다.

작업자 보임 7장(서 있음 3, 누움 4), 안 보임 54장, 판단 불가 0장이다. 사용자가 직접 판독한 기존 개발 자료이며, 제3자의 독립 판독이나 시뮬레이터 세그멘테이션 정답이 아니다. 이전 노출 표시가 6장 있다. 61장은 10회 실행에서 나온 서로 다른 프레임이며, 누움 4장은 2회 실행, 서 있음 3장도 2회 실행에서 나왔다.

검출 조건: 기존 YOLO11n / confidence 0.25 / 640 px / CPU. 채점은 사전에 설명한 **보이는 작업자 박스와 IoU ≥ 0.5**를 사용한다. 한 작업자에 검출 박스 하나만 매칭하고 나머지는 미매칭으로 센다. 게이트 통과는 검출 후보가 정확히 하나일 때다. 검출기를 새로 실행하거나 모델·런타임 설정을 바꾸지 않았다.

## 현재 설정의 결과

| 지표 | 결과 |
| --- | ---: |
| 작업자 위치 검출 재현율 | **6/7 (85.7%)** |
| 서 있는 작업자 위치 검출 | **3/3 (100%)** |
| 누운 작업자 위치 검출 | **3/4 (75%)** |
| 작업자 안 보임 프레임에서 사람 후보 검출 | **37/54 (68.5%)** |
| 작업자 안 보임 프레임의 단일 후보 게이트 통과 | **24/54 (44.4%)** |
| 자세가 읽히는 관측의 게이트 거부 | **0/7** |

검출 박스 전체 71개 중 정답 박스와 매칭되는 것은 6개이고, 미매칭은 65개다. 프레임 단위 오검출률과 박스 단위 정밀도 6/71은 다른 지표다. 검출 실행 오류는 0건이다.

**F009는 작업자를 아예 놓친 사례가 아니다.** 검출 박스가 누운 작업자 위에 있지만 사람 판독 박스보다 좁아서 IoU가 0.422였다. 원래 기준에 따라 위치 검출 실패로 유지했다. 이 프레임을 배경 검출로 잘못 해석하거나 사용자 박스를 사후 수정해서 성공으로 만들지 않았다. 게이트는 이 관측도 통과시키므로 0/7 거부가 검출 박스의 정확성을 뜻하지 않는다.

작업자 안 보임 54장의 출처별 결과:

| 카메라 | 프레임 수 | 단일 오검출 | 복수 오검출 | 후보 없음 |
| --- | ---: | ---: | ---: | ---: |
| 고정 카메라 | 23 | 22 | 0 | 1 |
| 로봇 카메라 | 31 | 2 | 13 | 16 |

고정 카메라의 배경 장치를 반복해서 사람으로 찾는 현상이 크다. 이를 발견했다고 고정 카메라 프레임을 사후 제외하지 않는다. 이전 5건 재생에서 잘 막힌 것만으로 검출기 성능을 대표할 수 없었다.

초록은 사용자 박스, 붉은색은 YOLO 박스다. 사례는 IoU 미달 양성 1장과 카메라·후보 수별 높은 confidence 오검출을 진단용으로 선택했다. 독립 평가 표본이 아니다.

## 다음 실행 결정

1. 현재 0.25로 40회 본 비교를 시작하지 않는다.
2. 0.60을 개발 후보로 고정하고, 아직 사용하지 않은 서 있음·누움·가림·배경 프레임에서 같은 기준으로 확인한다. 특히 누움 4장/2회 실행이라는 현재의 작은 범위를 보완한다.
3. 새 자료에서 재현율과 배경 거부를 확인한 뒤 게이트 OFF/ON 비교를 진행한다. 이번 결과만으로 다른 검출기 교체가 필요하다거나 YOLO가 누운 사람을 전반적으로 못 찾는다고 단정하지 않는다.

현재 런타임 config는 0.25 그대로이며, 새 40회 비교를 실행하지 않았다. 위치별 배경 제거 같은 규칙도 사후 추가하지 않았다. 이 결과는 검출 경로의 약점을 확인한 개발 진단이며, TRACE의 온라인 성능 개선 수치가 아니다.

평가 로직 6개 테스트 통과: IoU 경계, 배경 단일 후보, 중복 후보, 검출기 오류, 미정 라벨, 임계값 증가로 오검출 게이트가 새로 통과하는 경우. 별도 계산 검토에서 핵심 수치와 원본 61장·10회 trial 결과 해시를 확인했다. 이는 계산 검토이며 별도의 사람 정답 검토가 아니다. 생성된 두 그림을 직접 열어 확인했다.
