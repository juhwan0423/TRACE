# TRACE 개발 비교: 2026-11-07

Spark 연결을 복구한 뒤 기존 Qwen3-VL 8B와 Isaac Sim 6.2로 예정된 **10개 실행을 모두 완료**했다. 실행기 종료 코드는 0이며, 누락·무결성 차단·정리 실패 표시는 없다. **이번 결과는 TRACE의 성능 이득을 입증하지 못한다.** 논문용 확정 비교로 취급하지 않는다.

## 수행 범위

- 기존 연구실 장면, 시뮬레이션 Spot, 고정/몸체 RGB, 원래 Spark 모델을 유지했다.
- 고정 순서와 TRACE를 5개 조건에서 짝지었다. 독립 환경 5개가 아니라 **한 연구실의 3개 배치와 자세/관측 조건 변형**이다.
- 정책에 실제 작업자 좌표·자세·segmentation을 전달하지 않았다. 외부 정답은 평가에만 사용했다.
- 동일한 관측 해석기, 근거 검사, 12개 행동 예산, 300초 simulation/900초 wall 기한을 적용했다.
- 출발점은 작업자 확인 요청이다. CCTV 관측 소실부터의 종단간 비교나 낙상 역학 실험은 아니다.

**정답 라벨 일치와 근거 있는 답변은 다르다.** 확정 자세 답변 5개에 연결된 원본 RGB를 사후 검토한 결과, 2개는 지지됐고 3개는 대상 작업자를 식별할 수 없어 지지되지 않았다. 고정 순서의 정답 라벨 2개 중 1개도 여기에 해당한다. 확인 가능한 조건에서 RGB가 지지한 답은 양 정책 각각 1/3이었다. 이 숫자는 비블라인드 모델 보조 시각 감사이며, 독립 인간 주석이나 동결된 주 평가의 대체 지표가 아니다.

## 무엇이 막혔는가

1. **내용 검증:** VLM이 작업자가 없는 화면에서도 사람/서 있는 자세를 단정했다. 유효한 JSON, 새 프레임, 모델이 스스로 보고한 제한 없음은 영상 판독의 정확성을 보장하지 않았다.
2. **응답 신뢰성:** 61개 시각 호출 중 3개가 4096 출력 토큰을 소진하고 빈 최종 응답을 반환했다. 이 3개 근거는 처리 시점에 45 simulation-second TTL도 넘겼다. 전송 실패·최종 JSON 실패·근거 만료는 별개다.
3. **장면 재현:** 배경 문의 구동 목표/시간 위상이 시험 간 맞춰지지 않았고, 실제 물리 자세·속도의 리셋도 검증되지 않았다. 사후 점검에서는 문이 구동 목표를 정상적으로 따르지 못했다. 따라서 위상 차이가 실제 영상이나 정책 결과를 바꿨다고 단정하지 않는다. 북쪽 작업자 경로에는 좁은 통과 구간이 있었고, 한 정책만 이동에 실패했다. 그 차이를 적응적 계획의 인과적 효과로 분리할 수 없다.

누운 사람 조건에서 TRACE가 놓친 직접 원인은 JSON 실패나 TTL이 아니었다. 서쪽의 세 관측은 유효하고 신선했지만 VLM 해석/제한 표시가 종료를 막았다. 고정 순서의 대응 영상과 구도도 조금 달라, 구도와 모델 변동의 기여는 분리하지 못한다.

## 완료 기준과 다음 단계

비교 실행기·기준선·실측 비용·원본 근거·실패 기록은 확보했다. 현재 조건에서 반복 수만 늘려 논문 성능 주장으로 넘어가면 안 된다. 다음 확정 비교 전에는 대상 작업자의 존재/자세에 대한 별도 근거 검증, 문 상태와 경로 여유의 실제 확인, 미사용 배치 고정이 필요하다. 근거 검사 효과의 ablation과 실제 소실 트리거부터의 비교도 도구 선택 효과와 구분해야 한다.

추가 진단은 기존 10개 결과와 분리했다. [Qwen 요청 방식 점검](QWEN_VISION_PROBE_PROTOCOL.md)은 네 이미지에 두 방식, 총 8회 호출을 완료했다. strict JSON은 양쪽 4/4이며, wall 지연 중앙값은 기존 46.228초, 후보 2.956초였다. 다만 후보가 lying 이미지에 추가 관측을 요구해 현재 근거 검사 통과 여부도 달라졌다. 인식·종료 성능의 동등함이나 정책 개선을 입증한 결과가 아니므로 기존 어댑터는 유지했다.

문 닫힘 진단은 **실패**했다. 닫힘 목표 0도를 준 뒤 60초 동안 172개 물리 상태를 측정했지만, 자세 오차가 45.40–45.49도여서 기존 허용 기준을 통과하지 못했다. 점검 전 상태에도 비슷한 변위가 기록돼 있었으며 원인은 아직 분리하지 못했다. 원래 구동 일정·작업자 애니메이션·문 스키마와 소유권은 복원했고, 소스 자산은 그대로다. [측정 요약](../artifacts/trace_comparison_readiness/gate_validation_v1/summary.json)과 [복원 확인](../artifacts/trace_comparison_readiness/gate_validation_v1/final_handoff.json)을 보존했다. 이 보조 도구를 검증된 장면 수정으로 취급하지 않는다.

새 요청 방식이나 문 제어를 기존 10개 실행에 소급 적용하지 않았다. 정확한 실행 명령과 검증 수준은 [작업 기록](WORKLOG.md)에 있다.

## 소프트웨어 검증

`PYTHONPATH=src .venv/bin/python -B -m unittest discover -s tests`: **214개 통과, 4.250초**. 이는 CPU/설치된 USD 계약 검증이며 인식 정확도나 정책 우월성 검증이 아니다. 실제 렌더·보행·Spark 추론은 위 10개 실행 기록으로 구분했다. 실제 로봇, ROS/Nav2, 유료 API는 이번 실행에 사용하지 않았다.
