# TRACE 비교 실험 규약

2026-11-07. 이번 범위는 기존 Real2Sim 실험실의 시뮬레이션 Spot과 Spark Qwen3-VL 8B를 이용한 관측 선택 비교다. PSQ, 컨베이어, 새 휴머노이드, 실제 로봇은 포함하지 않는다.

## 연구 질문과 주장 범위

동일한 카메라, 시각 해석 모델, 관측 근거 검사, 후보 관측 위치와 대응 기한에서, TRACE의 적응적 도구 선택이 고정 순서 확인보다 관측 가능한 사람의 자세 질문을 정확하게 해소하는가? 비용은 이동 거리 추정치, 관측/계획 호출 시간, 도구 호출 수, 사건 처리 시간으로 함께 측정한다.

이번 비교의 시작은 **동일한 작업자 확인 요청**이다. 실제 CCTV 소실 검출부터의 종단간 성능이라고 표현하지 않는다. 이전 실제 positive→negative 소실 데모는 별도 개발 증거이며 이번 시험 수에 합치지 않는다. 사람은 위치와 자세를 정해 둔 skinned actor다. 실제 낙상 역학, 부상 진단, 미래 예측을 검증하지 않는다.

누운 자세는 이 실험의 위험 알림 대리 표적이다. 서 있다는 자세 확인은 전체 안전 확인이 아니다. 모든 정책에 같은 근거 검사를 적용하므로, 동일하게 0인 잘못된 안전 종료율을 TRACE 도구 선택의 이득으로 주장하지 않는다.

## 비교 조건

| 조건 | 선택 방식 | 공통 부분 |
|---|---|---|
| Fixed order | fixed 최대 2회 → entrance → west → door, 도착마다 body 최대 2회, 미해결이면 인계 | Qwen 영상 해석, Harness, 근거 만료·품질 검사, 후보 이동 경로 |
| TRACE | 공개 문맥과 도구 목록을 보고 같은 Qwen이 다음 행동 선택 | 위와 동일 |
| Camera only (선택적 보조) | 고정 카메라 최대 2회 후 미해결 인계 | 동일 영상 해석·종료 검사; 이동 없는 참조 |

공통 설정은 `configs/comparison_real2sim.json`으로 고정한다. 12개 행동은 고정 순서 정책이 카메라 2회, 이동 3회, body 6회와 최종 인계를 수행할 수 있는 상한이다. 실제 시간 기한이 먼저 끝나면 그대로 시간 초과 처리한다. 더 빠른 규칙 계획과 Qwen의 계획 지연 차이는 실측 비용이다.

고정 순서는 모델 비교 결과를 보기 전에 실제 초기 위치인 entrance부터 시작하도록 정했다. 출발점 body 영상을 먼저 확인하고 기존 통로를 따라 west, door를 탐색한다. 향후 다른 고정 순서가 필요하면 별도 사전 고정한 비교군으로 추가한다.

door의 yaw=2.9는 북쪽 통로를 보는 새 공통 후보다. 과거 -2.0 설정의 실행과 직접 풀링하지 않는다. 어떤 정책에도 실제 사람 좌표·자세, 가시성 정답, segmentation 또는 평가용 파일명을 제공하지 않는다. 모델에는 실제 새 RGB의 해석과 장소의 일반 설명만 제공한다.

## 장면, 분할, 실행 순서

가시성은 먼저 실제 렌더와 후보 위치 이동으로 검증한다. 사람이 화면에 몇 픽셀 존재한다는 사실만으로 자세가 판독 가능하다고 단정하지 않는다. 정답과 판독 가능성은 별도 외부 annotation이며, 근거가 부족한 조건은 확정 실험에 포함하지 않는다.

개발 파일럿과 확정 실험은 별도 manifest와 별도 결과 디렉터리다. 과거 성공 장면이나 파일럿을 보고 설계를 수정했다면 개발 결과로 남긴다. 기존 장면의 작은 좌표 변화와 같은 actor 반복을 서로 독립적인 환경으로 과장하지 않는다. 파일럿 표본의 bootstrap 구간은 탐색적이며, 적은 독립 배치에서 논문 수준의 일반성을 보장하지 않는다.

각 scenario/repetition에서 모든 정책을 짝지어 실행한다. 블록 순서는 고정 seed로 섞고, 선행 정책은 블록마다 순환하여 순서 효과를 줄인다. 리셋은 Spot articulation 초기화와 6 simulation seconds 안정화, actor의 명시적 정지 자세 적용이다. 전체 PhysX 상태의 정확한 복원은 아니다. 실제 초기 pose와 시각을 매번 저장한다.

## 고정과 재현

`run_real2sim_comparison.py freeze`는 모델 digest/Ollama 버전, 코드 사본과 SHA256, 설정, 외부 장면 manifest, 예정된 전체 순서를 저장한다. 이후 실행은 소스·모델·protocol 불일치를 거부한다. 기존 시험은 덮어쓰지 않는다. 중단된 시험을 묵시적으로 재실행하지 않는다.

각 시험에는 `started.json`, `preparation.json`, `events.jsonl`, RGB 원본, `result.json`, `record.json`, 별도 `external_truth.json`이 남는다. `summary.json`은 정책별 짝 누락뿐 아니라 전체 예정 시험 중 양쪽 모두 누락된 시험도 표시한다. 실행 오류와 시간 초과를 제거하지 않는다. 모델 서버가 바뀌면 새 실험으로 분리한다.

## 지표

1. 판독 가능한 시험에서 **정확하게 해소한 비율**. unknown, 시간 초과, 오류도 분모에 남는다.
2. 판독 불가능한 시험에서 자세를 단정한 비율. 올바른 unknown 인계는 기대 응답 적합도에는 포함하되 자세 질문 해소와 구분한다.
3. 누운 자세 표적의 실제 위험 확인 및 알림 시간, 미확인율. 단순 unknown 인계를 위험 확인으로 세지 않는다.
4. 전체 비용: 도구 수, 측정한 계획/영상 호출 지연(취소 포함), wall/simulation 시간, 샘플링한 로봇 중심 XY 이동 거리. 이동 중 외에도 자세 유지 드리프트가 포함되는 추정치이며 실제 연속 궤적 길이와 동일하지 않다.

현재 host는 서 있는 자세 질문을 해소한 경우에도 전체 안전이 확립되지 않았다는 인계 이벤트를 남긴다. 따라서 unknown-handoff 횟수와 자세 질문 미해소율은 같지 않다. 이 인계를 곧바로 불필요 신고라고 해석하지 않는다.

시각은 사건 시작을 0으로 바꾼 평가용 상대 시각과 원래 simulator 시각을 함께 보존한다. 누운 배우의 onset=0은 확인 요청 시점이지 실제 추락 발생 시점이 아니다. 구별 가능한 영상 시각과 단정 근거의 충분성은 외부 검토가 없으면 missing으로 둔다.

짝 비교는 scenario 안에서 반복의 차이를 평균한 뒤 scenario를 같은 가중치로 bootstrap한다. 반복 프레임을 독립 표본으로 세지 않는다. 1개 scenario에서는 신뢰구간을 내지 않는다. 정책별 평균은 시험 단위, 짝 차이는 scenario 단위이므로 반복 수가 다르면 단순 평균 차이와 같지 않을 수 있다.

## 논문 완료에 남는 검증

실행기와 파일럿만으로 논문 비교가 완료되지는 않는다. 별도로 고정한 미사용 배치에서의 비교, 가림·판독 불가·지연/실패 조건, 충분한 독립 배치와 불확실성, 실제 소실 트리거부터의 반복 검증이 필요하다. 근거 검사 자체의 효과는 도구 선택 비교와 분리한 ablation으로 평가해야 한다. 새 결과가 나오기 전 우월성이나 개선율을 주장하지 않는다.
